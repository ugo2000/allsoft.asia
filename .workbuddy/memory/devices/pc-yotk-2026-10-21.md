## Markdown for Agents 内容协商（已上线）

- 需求：站点支持 `Accept: text/markdown` 内容协商，让 AI 智能体直接拿 markdown 版页面
- 方案：`functions/_middleware.js` 应用层实现（Cloudflare 原生 Markdown for Agents 需 Pro/Business，本站免费套餐）
- 产出：
  - `functions/_middleware.js`：内容协商 + 零依赖 HTML→Markdown 转换器（frontmatter + 正文 + JSON-LD 块，输出格式对齐 CF 官方规范）
  - `test/markdown-negotiation.test.mjs`：25 条 node --test 单测全绿（转换器 + 中间件 + 全站 22 页冒烟）
  - 响应头：`Content-Type: text/markdown; charset=utf-8`、`Vary: Accept`、`x-markdown-tokens`、`content-signal: ai-train=yes, search=yes, ai-input=yes`
  - llms.txt / README 补 Agent Access 说明
- 线上验证：isitagentready.com 扫描 `markdownNegotiation: pass`，站点 Level 3「Agent-Readable」
- 部署：`npx wrangler pages deploy . --branch main`（两次：初版 + 修复版）
