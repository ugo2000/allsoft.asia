## 主题按钮无效修复：缓存（commit 02adac2）

- 用户反馈"按钮没变化"→ 根因：_headers 对 *.css 设 Cache-Control max-age=31536000（1 年），页面引用 css/style.css?v=2 未 bump → 浏览器/CDN 用旧 CSS（无 html.dark 样式），点击 🌙 只是加了 html.dark 类但样式不存在
- 修复：全站 17 页 css?v=2→?v=3；顺带 18 页 js/i18n.js 加 ?v=2（上轮 i18n.js 新增 t()/i18n:change 也受缓存影响）
- 项目惯例（重要）：_headers 对 css/js 1 年强缓存，**改 css/js 后必须 bump 引用版本号**，否则线上永远旧版；改完 curl 线上带 ?v= 校验

## 主题缓存死结彻底解决：CSS 文件名版本化（commit 093c23e）

- 用户仍反馈"没有改变 / 深色字看不清"→ 排查确认根因：Cloudflare Pages CDN 按路径缓存 css，**忽略 ?v= query**，_headers 又设 1 年缓存 → 无论怎么 bump ?v=，CDN/用户都拿旧 css（实测 production 返回旧内容，部署快照 .pages.dev 是新内容）
- 解法：css/style.css 复制为 **css/style.v5.css（新文件名=新 URL=必然回源）**，全站 17 页引用切换
- **项目新规（重要）**：改 css 后必须同步复制到 style.vN.css 并切换全站引用；js 同理（js/xxx.vN.js 或依赖内容更新）；OAuth token 无 purge_cache 权限，不要指望清缓存
- 附带：暗色对比度提升（color-scheme: dark 原生控件反色 + --c-text/#e8edf5、--c-text-light/#a6b4c8 提亮）
- 验证：style.v5.css 新路径线上立即返回最新内容 ✓

## 后台流量图表升级为 SVG 折线图（commit 3c4f774/07af5e0）

- 根因：原柱状图 filter(pv>0) 后若只剩 1 天数据，flex:1 的 .bar 撑满 200px 图表区，呈现大蓝块覆盖（"卡不到曲线被覆盖"）
- 修复：bar-chart → line-chart（SVG 折线图，30 天全部点连线，0 值点画在基线，浏览器原生 title hover tooltip）
- 暗色：line 变浅蓝、pt 描边深色、grid/axis 跟随暗色变量
- 验证：浅色+暗色各截图确认（30 天 0 基线 + 8-19 174 尖峰趋势清晰）
- 顺手：theme.js 加 ?theme=dark/light URL 参数（方便分享深色链接 + 截图调试；URL > localStorage > 系统偏好）
- theme.js 加 ?v=2 破 1 年 CDN 缓存
