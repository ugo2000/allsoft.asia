## 修复 team.py curl 中文乱码（commit 6bb3937）

- 对端 mmfd8440 回信说"乱码解决不了"，经排查根因在 team.py 第43行
- `json.dumps(payload, ensure_ascii=False)` 把原始中文字符直接塞进 curl `-d` 参数
- Windows curl 按系统码页（GBK/cp936）处理非 ASCII 字节 → 中文被截断或变乱码
- 修复：改为 `json.dumps(payload)`（ensure_ascii=True 默认），JSON 中文变 \uXXXX 转义纯 ASCII 传输，curl 不受码页影响，服务端 request.json() 自动还原
- watch.py 本就正确（用默认 ensure_ascii=True），补了显式标注和 decode("utf-8")
- 实测：发中文消息到总线，D1 存储和读取都正常（消息 #14 验证通过）
